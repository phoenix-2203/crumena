## Colour

Stone and graphite. The only colour is the cognac of the mark, plus green and red for status.

| Token | Light | Dark |
|---|---|---|
| Paper | `#efeee9` | `#0e0e0d` |
| Surface | `#f8f7f3` | `#161615` |
| Ink | `#111111` | `#ecebe6` |
| Muted ink | `#5e5d58` | `#9a9993` |
| Rule | `#d8d6ce` | `#2b2b29` |
| Mark | `#a5531f` | `#d98a50` |
| Button | `#111111` on `#f8f7f3` | `#ecebe6` on `#0e0e0d` |

Every text colour meets WCAG 2.1 AA in both themes (checked with axe-core on every page).

## Type

- **Familjen Grotesk**: everything you read, set light and large for headlines
- **IBM Plex Mono**: amounts, addresses, labels and signed statements

Both are under the SIL Open Font License and are bundled into the app, served from Crumena's own origin.
