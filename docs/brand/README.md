## Colour

Stone and graphite, with one copper gradient: the mark, the headline word, bars and the glow. Green and red are only for status.

| Token | Light | Dark |
|---|---|---|
| Paper | `#efeee9` | `#0e0e0d` |
| Surface | `#f8f7f3` | `#161615` |
| Ink | `#111111` | `#ecebe6` |
| Muted ink | `#5e5d58` | `#9a9993` |
| Rule | `#d8d6ce` | `#2b2b29` |
| Mark (solid) | `#a5531f` | `#d98a50` |
| Copper gradient | `#6e3210` → `#b25d27` → `#d98a50` | `#f6d2b0` → `#e39a62` → `#b8622b` |
| Button | `#111111` on `#f8f7f3` | `#ecebe6` on `#0e0e0d` |

Every text colour meets WCAG 2.1 AA in both themes (checked with axe-core on every page).

## Type

- **Bodoni Moda**: headlines and large amounts
- **Instrument Sans**: everything you read
- **IBM Plex Mono**: addresses, labels, amounts in lists and signed statements

Both are under the SIL Open Font License and are bundled into the app, served from Crumena's own origin.
